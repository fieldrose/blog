## 开发环境

### hello world

```java
// 1. public class Hello 声明一个 public 公有的 Hello 类
// 2. Hello{} 表示一个类的开始和结束
// 3. public static void main (String[] args){}表示主方法，即程序入口
// 4. main(){}表示方法的开始和结束
// 5. System.out.println 输出内容，System是 JDK 中 java.lang 包下的一个核心类
public class Hello {
    // 方法
    public static void main (String[] args){
        System.out.println("hello word");
    }
}
```

```bash
# 同级目录下
# 编译
javac Hello.java
# 运行 编译后的类名实际上不带.java或.class后缀
java Hello
```

### 对于java代码中中文的处理

需要注意终端使用的编码要和java代码中的编码一致，例如需要统一使用UTF-8编码或GBK编码，否则会导致编译错误。
