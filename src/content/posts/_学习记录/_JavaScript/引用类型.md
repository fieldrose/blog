## Table of contents

## 引用类型

本篇按「内置对象 → 集合 → 二进制视图」的顺序整理 ECMAScript 提供的引用类型。切入角度不在逐个 API 罗列，而在各类型的实例行为、比较语义与适用边界：数组空位如何影响遍历，`sort` 为何默认按字符串比较，`WeakMap` 的键为何必须是对象，定型数组的多个视图为何互相影响。

### 1. 基本引用类型

引用类型的实例由构造函数创建，`new` 返回对象，对象的原型指向构造函数的 `prototype`。Date 与 RegExp 是使用频率较高的两个内置构造器，原始值包装类型则用于在原始值上临时调用方法。

#### 1.1 Date

`new Date()` 返回当前时间，也可以传入毫秒时间戳、ISO 8601 字符串或年月日等分量。月份从 0 开始，`getMonth()` 的返回值需要加 1 才符合日常认知。`Date.now()` 直接返回毫秒时间戳，避免创建实例。字符串解析的实现差异较大，跨环境传递时间时使用 ISO 8601 或时间戳。

```js
const now = Date.now();

const date = new Date(2026, 10, 18); // 本地时间，月份从 0 开始
date.toISOString(); // 按 UTC 输出，结果随本地时区变化

const utc = new Date(Date.UTC(2026, 10, 18));
utc.toISOString(); // "2026-11-18T00:00:00.000Z"

const parsed = Date.parse("2026-11-18T00:00:00Z");
```

#### 1.2 RegExp

正则可以用字面量或构造函数创建，字面量在解析期编译，适合固定模式；构造函数接收字符串，适合动态拼接。标志位包括 `g`（全局）、`i`（忽略大小写）、`m`（多行）、`s`（点匹配换行）、`u`（Unicode）、`y`（粘附）、`d`（返回索引）。`exec` 返回匹配数组并携带 `index`、`input`、`groups`，`test` 只返回布尔值；带 `g` 或 `y` 时，`lastIndex` 会跨调用保留，复用同一个正则实例需要留意状态。

```js
const re = /(\d{4})-(\d{2})/g;
const match = re.exec("2026-11");

match[0]; // "2026-11"
match.index; // 0
re.lastIndex; // 7，下一次 exec 从这里继续
```

#### 1.3 原始值包装类型

Boolean、Number、String 既是原始类型，也有对应的包装构造函数。以 `new` 调用返回对象，直接调用返回原始值。读取原始值的属性或方法时，引擎自动创建临时包装对象，调用结束后销毁，因此原始值上的属性赋值不会保留。日常代码应避免 `new Number()`、`new Boolean()` 这类显式包装，`new Boolean(false)` 是对象，在条件判断中恒为真。

```js
const s = "text";
s.length; // 4，自动装箱

typeof new String("text"); // "object"
typeof String("text"); // "string"

if (new Boolean(false)) {
  // 会进入，因为对象为真值
}
```

### 2. 单例内置对象

Global 与 Math 不属于引用类型的实例，而是全局单例。Global 在浏览器中由 `window` 代理，在 Node.js 中为 `globalThis`；Math 提供数学常量与函数，属性只读。

#### 2.1 Global

Global 上挂载 `encodeURI`、`encodeURIComponent`、`parseInt`、`parseFloat`、`isNaN`、`eval` 等函数。编码整段 URL 用 `encodeURI`，编码参数值用 `encodeURIComponent`，后者会转义 `&`、`=`、`?` 等分隔符。ES6 之后，部分方法迁移到对应构造器，例如 `Number.parseInt`、`Object.keys`，规范层面的 Global 更像一个抽象对象。

```js
encodeURIComponent("a b&c"); // "a%20b%26c"
Number.parseInt("42px", 10); // 42，解析到非数字为止
Number.isNaN(Number("abc")); // true
```

#### 2.2 Math

`Math` 提供 `PI`、`E` 等常量与 `min`、`max`、`ceil`、`floor`、`round`、`trunc`、`abs`、`pow`、`sqrt`、`random` 等方法。`Math.round` 对 `.5` 向正无穷方向取整，`Math.trunc` 直接截断小数部分，两者在负数上结果不同。生成区间随机整数的常用写法如下。

```js
Math.round(-1.5); // -1
Math.trunc(-1.9); // -1

const randomInt = (min, max) =>
  Math.floor(Math.random() * (max - min + 1)) + min;
randomInt(1, 10); // 1 到 10
```

### 3. Object 与 Array

Object 是所有引用类型的基类，Array 是最常用的有序集合。数组的能力集中在创建、检测、遍历、变换、排序与搜索几个维度，各方法的返回值与副作用需要区分：有的原地修改，有的返回副本。

#### 3.1 创建与数组空位

`new Array(3)` 或 `Array(3)` 传入单个数字时创建指定长度的稀疏数组，元素全部为空位；传入多个参数时按元素创建。`Array.of` 消除了这一歧义，`Array.from` 可从类数组或可迭代对象创建数组。空位（hole）与 `undefined` 不同：`length` 计入空位，大多数遍历方法跳过空位，`Array.from` 会把空位转成 `undefined`。

```js
new Array(3).length; // 3，稀疏数组
Array.of(3); // [3]
Array.from({ length: 3 }); // [undefined, undefined, undefined]

const sparse = [1, , 3];
sparse.map((v) => v * 2); // [2, <1 empty item>, 6]
```

#### 3.2 检测与迭代器方法

`Array.isArray` 是跨 realm 可靠的检测方式，`instanceof Array` 在多窗口环境会失效。迭代器方法返回真正的迭代器：`keys`、`values`、`entries`。判定类方法 `some`、`every` 短路返回布尔值，`find`、`findIndex`、`findLast` 按查找方向返回匹配项或其索引，`filter` 与 `map` 返回新数组，`forEach` 无返回值。

```js
const list = [1, 2, 3, 4];

Array.isArray(list); // true
list.find((v) => v > 2); // 3
list.every((v) => v > 0); // true
[...list.entries()]; // [[0, 1], [1, 2], ...]
```

#### 3.3 复制、填充与转换

`fill` 与 `copyWithin` 原地修改数组，`slice`、`concat`、`flat`、`flatMap` 返回新数组。`fill` 传入对象时填充的是同一个引用，多个位置共享该对象。转换方面，`join` 指定分隔符，`toString` 等价于用逗号连接，`toLocaleString` 按区域设置格式化。

```js
const arr = [1, 2, 3, 4];

arr.slice(1, 3); // [2, 3]，不修改原数组
arr.fill(0, 2); // [1, 2, 0, 0]，原地修改

[1, [2, [3]]].flat(2); // [1, 2, 3]
[1, 2].join("-"); // "1-2"
```

#### 3.4 栈、队列与排序

`push` 与 `pop` 在尾部操作，构成栈；`shift` 与 `unshift` 在头部操作，配合 `push` 构成队列。`shift` 需要移动后续元素，复杂度为 O(n)，大数组上频繁出队应改用索引游标或双端队列。`sort` 默认把元素转成字符串按 UTF-16 码元比较，数字数组必须传比较函数；`toSorted` 返回排序后的副本，不修改原数组。

```js
const stack = [];
stack.push(1);
stack.pop(); // 1

const nums = [10, 2, 1];
nums.sort(); // [1, 10, 2]，按字符串比较
nums.sort((a, b) => a - b); // [1, 2, 10]
nums.toSorted((a, b) => b - a); // [10, 2, 1]，原数组不变
```

#### 3.5 操作与搜索

`splice` 集删除、插入、替换于一体，原地修改并返回被删除的元素；`concat` 拼接数组或值，返回新数组。搜索方法中，`indexOf`、`lastIndexOf` 使用严格相等，无法查找 `NaN`；`includes` 改用 SameValueZero，可以判断 `NaN`。需要按条件查找时用 `find`、`findIndex`。

```js
const arr = [1, 2, 3, 4];

arr.splice(1, 2, "a"); // 返回 [2, 3]，数组变为 [1, "a", 4]
arr.includes(NaN); // false
[NaN].includes(NaN); // true
[NaN].indexOf(NaN); // -1
```

#### 3.6 归并

`reduce` 与 `reduceRight` 把数组折叠为单个值，回调接收累加器、当前值、索引和原数组。传入初始值时从第一个元素开始遍历；省略初始值时以第一个元素为初始累加器，空数组会抛 `TypeError`。累加器返回对象或数组时需显式返回，箭头函数的简写会隐式返回错误类型。

```js
const total = [1, 2, 3].reduce((sum, v) => sum + v, 0); // 6

const grouped = ["a", "bb"].reduce((acc, word) => {
  acc[word.length] = word;
  return acc;
}, {});
// { 1: "a", 2: "bb" }
```

### 4. 定型数组

定型数组用于处理二进制数据，例如 WebGL、音频、文件解析和网络协议。`ArrayBuffer` 是一段定长的原始字节缓冲区，本身不能读写，必须通过视图访问；多个视图可以共享同一块缓冲区，任一侧的写入对另一侧立即可见。

#### 4.1 ArrayBuffer

`new ArrayBuffer(byteLength)` 分配指定字节数的内存，`byteLength` 只读，`slice` 返回副本。缓冲区一旦分配，长度不可变；扩容需要新建缓冲区并复制数据。

```js
const buffer = new ArrayBuffer(8);
buffer.byteLength; // 8

const copy = buffer.slice(0, 4);
copy.byteLength; // 4
```

#### 4.2 视图：TypedArray 与 DataView

TypedArray 是一组构造器的统称，包括 `Int8Array`、`Uint8Array`、`Int32Array`、`Float64Array` 等，元素类型和长度固定，读取时按元素类型解释字节。`DataView` 更灵活，可以在任意偏移处按指定类型读写，并通过第二个参数控制大小端，`true` 表示小端。TypedArray 越界写入会被静默忽略，`DataView` 越界会抛 `RangeError`。

```js
const buffer = new ArrayBuffer(8);
const view = new DataView(buffer);
view.setInt32(0, 42, true); // 小端写入
view.getInt32(0, true); // 42

const bytes = new Uint8Array(buffer);
bytes.length; // 8
bytes[0] = 1; // 与 view 共享同一缓冲区
```

### 5. Map 与 WeakMap

Map 保存键值对，键可以是任意类型，包括对象、函数和 `NaN`。与普通对象相比，Map 不会把键转成字符串，保留了键的原始类型，并且迭代顺序稳定为插入顺序。WeakMap 的键限定为对象，且是弱引用，不阻止键被回收。

#### 5.1 基本 API

`set`、`get`、`has`、`delete`、`clear` 覆盖增删查改，`size` 是属性而非方法。键的比较使用 SameValueZero，`NaN` 与 `NaN` 视为同一个键，`+0` 与 `-0` 视为相同。`set` 返回 Map 本身，支持链式调用。初始化可以直接传入包含键值对的二维数组或另一个 Map。

```js
const map = new Map([["a", 1]]);

map.set("b", 2).set("c", 3);
map.get("a"); // 1
map.has("b"); // true
map.size; // 3

const objKey = {};
map.set(objKey, "value"); // 对象作为键，不会被字符串化
```

#### 5.2 顺序与迭代

Map 按插入顺序迭代，`keys`、`values`、`entries` 与 `forEach` 均遵循该顺序，删除后重新插入的键排到末尾。`for...of` 默认迭代 `entries`，可以直接解构为 `[key, value]`。普通对象的属性顺序规则更复杂（整数键优先），需要严格顺序时选择 Map。

```js
const map = new Map([
  ["a", 1],
  ["b", 2],
]);

for (const [key, value] of map) {
  console.log(key, value); // a 1，然后 b 2
}

[...map.keys()]; // ["a", "b"]
```

#### 5.3 弱键的意义

WeakMap 的键是弱引用：当键对象在其他地方不再可达时，对应条目会被回收，即使 WeakMap 本身仍然存在。这一特性使它不适合做需要枚举的缓存，但适合把元数据绑定到对象上而不影响其生命周期。WeakMap 不可迭代，没有 `size`，也不提供 `clear`，键只能是对象或非全局注册的 Symbol。

```js
const meta = new WeakMap();

let node = document.createElement("div");
meta.set(node, { clicks: 0 });
// ...
node = null; // 条目随键一起可被回收
meta.has(node); // false
```

### 6. Set 与 WeakSet

Set 保存唯一值，重复添加同一值不会增加成员，判定同样使用 SameValueZero。Set 的成员顺序为插入顺序，常用于去重、成员检测和集合运算。WeakSet 只接受对象，弱引用语义与 WeakMap 一致，且不可迭代。

#### 6.1 基本 API 与迭代

`add`、`has`、`delete`、`clear` 与 `size` 构成基本操作，`add` 返回 Set 本身。Set 可迭代，`keys` 与 `values` 返回相同的迭代器，`entries` 返回 `[value, value]` 形式。`Array.from(set)` 或展开运算符可转回数组，这是数组去重的常见写法。

```js
const set = new Set([1, 2, 2, 3]);

set.size; // 3
set.add(4).add(1); // 重复的 1 被忽略
[...set]; // [1, 2, 3, 4]

const unique = [...new Set([1, 1, 2])]; // [1, 2]
```

#### 6.2 集合运算与选型

并集、交集、差集、对称差可以直接用 Set 构造，也可以使用新增的 `union`、`intersection`、`difference`、`symmetricDifference`、`isSubsetOf`、`isSupersetOf` 等方法，后者在运行时支持度上仍需确认。选型上：需要去重或 O(1) 成员检测用 Set；需要值到附加数据的映射用 Map；需要以对象为键且不希望影响回收，用 WeakMap 或 WeakSet；需要 JSON 序列化则用普通对象或数组。

```js
const a = new Set([1, 2, 3]);
const b = new Set([3, 4]);

new Set([...a, ...b]); // 并集 {1, 2, 3, 4}
new Set([...a].filter((v) => b.has(v))); // 交集 {3}
new Set([...a].filter((v) => !b.has(v))); // 差集 {1, 2}
```
