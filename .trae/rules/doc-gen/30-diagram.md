# 30 · 图表使用标准

> 维护说明：修改规则请直接编辑本文件，所有文档生成流程自动生效。

## 已固化规则

- **D1 必要性**：图表只用于文字表达效率低的场景（流程、架构、对比、时序），禁止装饰性图表；每个图表必须有正文引用与解释。
- **D2 可维护性**：优先使用文本化图表（Mermaid / dynamic-ui 组件），禁止用截图式图片充当架构图或流程图。

## 待补充（由用户逐条确认后转为正式条目）

- 图表类型选型规则（流程图 / 时序图 / 架构图分别用什么工具）
- 配色与主题约束（是否对齐博客明暗双主题）
- 表格与图表的选择阈值（数据量、维度）
- 插图资源规范（生成图片的 prompt 要求、尺寸、存放位置）

## 自检项（同步至 90-checklist）

- [ ] 图表均有正文引用（D1）
- [ ] 全部使用文本化图表，无截图式图片（D2）
