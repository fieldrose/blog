# doc-gen — 标准化文档生成

规则本体全部位于 `.trae/rules/doc-gen/`（00-context、10-style、20-code、30-diagram、40-format、90-checklist）。本 Skill 只做流程编排，不含规则本体；禁止在此硬编码规范条目，规则调整一律改规则库文件。

## 生成流程

规则库已由 Trae 会话自动注入（`.trae/rules/doc-gen/`），直接引用即可，无需手动 Read。

1. **确定类型与主题**：类型为 `blog`（博客文章）或 `tech`（技术文档）。用户未指定时按主题推断，无法确定则询问一次。
2. **生成文档**：
   - 开头固定注入「项目背景」区块（模板见 00-context.md），无需用户重复说明背景。
   - 正文严格遵循 10-style、20-code、30-diagram、40-format 的全部「已固化规则」。
   - 标注「待补充」的小节不臆造规则，按通用最佳实践处理，并在交付时提示这些小节待用户确认。
4. **自检**：对照 90-checklist.md 逐条核对，未通过项必须修正后再输出；交付时附简短自检结论。
5. **类型附加动作**：
   - `blog`：检查 frontmatter 是否符合 content collection schema，提醒 zh / en 双语页面要求。
   - `tech`：按 40-format 的命名与落盘约定存放（未固化时先与用户确认路径）。

## 维护流程

用户要求修改规则时：定位到对应编号文件 → 将「待补充」转为正式条目或调整现有条目 → 同步更新 90-checklist.md 的自检项与量化标准表 → 报告变更摘要。
